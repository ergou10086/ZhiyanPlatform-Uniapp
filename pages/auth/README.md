# 登录注册模块

## 功能说明

### 登录页面 (`login.vue`)
- **路径**: `/pages/auth/login`
- **功能特性**:
  - 用户名/邮箱登录
  - 密码可见性切换
  - 记住登录信息
  - 表单验证
  - 自动跳转到首页

### 注册页面 (`register.vue`)
- **路径**: `/pages/auth/register`
- **功能特性**:
  - 用户名注册（4-20字符，字母数字下划线）
  - 邮箱验证
  - 密码强度要求（至少6位）
  - 密码确认
  - 所属机构（选填）
  - 用户协议和隐私政策确认
  - 完整的表单验证

## API 接口

### 登录接口
```javascript
POST /api/auth/login
{
  "username": "用户名或邮箱",
  "password": "密码"
}

响应:
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "JWT Token",
    "userInfo": {
      "id": "用户ID",
      "username": "用户名",
      "email": "邮箱",
      ...
    }
  }
}
```

### 注册接口
```javascript
POST /api/auth/register
{
  "username": "用户名",
  "email": "邮箱",
  "password": "密码",
  "organization": "所属机构（可选）"
}

响应:
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "userId": "新用户ID"
  }
}
```

### 登出接口
```javascript
POST /api/auth/logout

响应:
{
  "code": 200,
  "message": "登出成功"
}
```

## 设计特点

- 渐变紫色主题，现代感强

- 输入框聚焦动画效果

### 安全性
- 密码输入隐藏
- 客户端表单验证

## 使用说明

1. **首次启动**: 应用会自动打开登录页面
2. **注册流程**: 点击"立即注册" → 填写信息 → 同意协议 → 注册成功 → 自动返回登录页
3. **登录流程**: 输入用户名和密码 → 登录 → 自动跳转首页
4. **记住密码**: 勾选"记住我"后，下次启动会自动填充登录信息

## 注意事项

- 登录页面作为应用首页，在 `pages.json` 中排在第一位
- Token 存储在本地 Storage 中，需要在请求拦截器中添加到请求头
- 建议后端实现 JWT Token 认证机制
- 密码传输建议使用 HTTPS 加密
